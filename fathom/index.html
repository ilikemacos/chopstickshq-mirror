Install

Downloads

Use the curl installer. Browser downloads get macOS’s quarantine flag, so Gatekeeper blocks the App ZIP on first launch; the installer writes the app straight to ~/Applications without it. Served from Chopsticks HQ (Netlify edge CDN). Artifacts track version.json.

1 · curl install (recommended)

Fetches the current App ZIP, verifies its SHA-256, and installs to ~/Applications/Fathom.app. No Xcode needed.

curl -fsSL https://chopstickshq.com/fathom/install-fathom.sh | bash
Download .sh

Always installs whatever version.json lists as current. To compile from source instead (needs Xcode Command Line Tools): install.sh.

2 · App ZIP — fallback

Unzip → open Fathom.app (branded Fathom Air). Gatekeeper will block this on first launch — right-click → Open, then Open again, or use the curl installer above instead.
