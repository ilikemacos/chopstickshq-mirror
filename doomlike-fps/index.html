What is it?

Doomlike-FPS™ (DOOMLIKE) v0.9-Beta-Pre-Release is a self-contained HTML raycast FPS — styled after classic corridor shooters, not a full 3D engine. One file game, runs in modern browsers.

  • Channel label: v0.9-Beta-Pre-Release
  • Wave survival against monsters
  • Health, armor, ammo HUD
  • Settings for FOV, sensitivity, render scale, fog
  • Optional cloud accounts via Supabase (if configured in the game)

Part of Chopsticks HQ

Shipped alongside tools like MacBar and Fathom. Games live under the same lab roof.

Default controls

  • Click — lock mouse / start
  • WASD — move
  • Mouse — look
  • Click / fire — shoot (see in-game Controls tab)
  • Esc — unlock / pause menu

Fine-tune FOV, aim, sensitivity, and more in the game’s Settings.
