Privacy

Short version: no accounts, no telemetry, your keys stay on your Mac.

What MacBar does not do

  • No user accounts or logins
  • No analytics SDKs or crash-reporting services built into the app
  • No advertising identifiers
  • No selling of personal data

What stays on your device

  • Live CPU, temperature, memory, battery, and related stats are read locally from macOS
  • AI API keys (when you use Chat) are stored with the system Keychain; beta builds encrypt chat history at rest (AES-256-GCM)
  • Preferences and thresholds stay in your user account on this Mac

Network requests

  • Updates — the app checks https://chopstickshq.com/macbar/version.json on launch
  • Optional BTC price — CoinGecko public API when that menu bar slot is enabled
  • AI Chat — only when you send a message, using your provider key to that provider (OpenAI, OpenRouter, etc.). We do not proxy chat through MacBar servers unless you use the website support widget
  • Website support chat (optional) — if enabled on the download site, messages go through a Netlify function to an AI provider configured by the site owner

Website

The download site is a static page hosted on Netlify. Standard host logs (IP, user-agent) may be collected by Netlify for operations and abuse prevention. We do not run third-party ad trackers on the MacBar pages.

Contact

Questions: use Support on the download page (redirects to a GitHub issue) or open a new issue.

This page describes the open-source MacBar apps and website as shipped. Third-party AI providers have their own privacy policies.
