Free Mac AI assistant without bringing your own API key

Many “free AI” apps still ask you to paste an OpenRouter, OpenAI, or Gemini key. cs.AI (chopsticksAI) is different for live chat: you install or open the app, ask a question, and answers route through chopstickshq.com — no key setup on your Mac.

There is a free allowance (resets every 5 hours). Optional unlock keys unlock higher tiers; they are not cloud API credits. Product help about Chopsticks HQ software can fall back to an on-device keyword knowledge base when offline.

Three ways to use cs.AI

  • macOS app — Cursor-style Agents window + Chromium browser rail
  • Web app — chopstickshq.com/chopsticks-ai/web/, no install
  • Terminal CLI — csai for shell and scripting (install guide)

What cs.AI is not

  • Not a local LLM running entirely on your GPU (live mode needs network)
  • Not affiliated with OpenAI, Anthropic, or Cursor
  • Not a hosted chat log — we don't keep analytics on what you ask in live mode
