Free open-source Mac menu bar system monitor

If you want live CPU, temperature, battery %, GPU, and RAM in the macOS menu bar — without a subscription or an account — MacBar is built for that. (You may still see the old name MacBar in listings and search.)

Many people search for a free alternative to paid menubar monitors (for example iStat Menus). MacBar is not affiliated with those products. It is free software with local sensors, optional AI using your keys, and no product telemetry.

What you get

  • Menu bar stats on macOS 14+
  • Battery % aligned with the system menu bar
  • Open install path (App ZIP or compile-from-source)
  • GitHub releases: ilikemacos/MacBar

Who it is for

Developers, power users, and anyone who wants a lightweight, honest monitor without cloud lock-in. Builds are ad-hoc signed today — first open may need right-click → Open.
