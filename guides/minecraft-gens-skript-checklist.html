Skript gens server checklist

A short checklist used when building and operating gens-style Minecraft servers (Skript, economy, ranks, builds, protection). For a live portfolio of servers worked on, see imik2261_.

1. Core loop

  • Clear generator → sell → upgrade path
  • Readable prices and rank goals in chat/UI
  • Anti-dupe and edge cases on sell/upgrade

2. Skript systems

  • Custom items and gens with consistent naming
  • Rank / permission gates that match progression
  • Logging for economy actions when debugging

3. WorldEdit / builds

  • Spawn and gen islands that support the loop
  • Schematics for re-deploy after wipe
  • Space for AFK / sell / warp hubs

4. WorldGuard

  • Protect spawn and critical regions
  • Flags for PvP, build, and entry where needed
  • Separate player islands vs public areas

5. Ops

  • Staff ranks with least privilege
  • Backup schedule before economy changes
  • Join IP and rules in a single place for players
