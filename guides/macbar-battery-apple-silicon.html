How MacBar shows MacBook battery % on Apple Silicon

MacBar aims to show the same charge percentage you see in the macOS menu bar, using local system sources — not a cloud service.

Where the number comes from

  • IOPS / IOKit — battery properties from the system power stack
  • pmset — power management status used as a cross-check
  • Remaining time — an estimate; it moves with load and is not a promise

A separate chemical “gauge” SoC can trail the menu bar by a few points. That is normal gas-gauge behavior, not necessarily a bug in the menu bar reading.

Privacy

Battery data stays on your Mac. MacBar has no product telemetry and no account. See Privacy.
