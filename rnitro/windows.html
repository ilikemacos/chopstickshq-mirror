About rNitro for Windows

Windows is no longer actively developed. The current build (v6.0.2-Windows-x64) is shipped as a ZIP — no installer, nothing written to the registry.

  • What it does — system tray icon with CPU %, temperature, RAM, optional BTC, and short history graphs
  • ZIP — unzip and run rNitro.exe; needs the .NET 8 Desktop Runtime (x64)
  • PowerShell installer — compiles with built-in csc.exe (no Visual Studio SDK)
  • No install path — the ZIP runs from wherever you unpack it; delete the folder to remove it

For new installs we recommend macOS or Linux.

How to install (legacy)

1

Download the ZIP (easiest)

Download rNitro-v6.0.2-Windows-x64.zip and unzip it anywhere. Right-click rNitro.exe → Properties → Unblock if Windows flags it, then run it. If Windows asks for a runtime, install .NET 8 Desktop Runtime x64 first.

2

Or compile from source

Download rNitro-v4.2.4-Windows-Final-x86.ps1, open PowerShell, and run:

powershell -ExecutionPolicy Bypass -File $env:USERPROFILE\Downloads\rNitro-v4.2.4-Windows-Final-x86.ps1
3

Use rNitro

rNitro runs in the system tray, not the taskbar. Click for live stats; right-click to quit. Run as administrator if you want real CPU temperatures — Windows hides thermal sensors from unelevated apps.
