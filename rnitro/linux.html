About rNitro for Linux

v0.1 Linux Beta Pre-release is a GTK 4 + libadwaita desktop companion to the macOS app — Monitor, Advisor, Chat, and App Cleaner on x86_64 Linux.

  • Status — pre-release; expect rough edges and platform gaps vs macOS
  • Requirements — Python 3.10+, GTK 4, libadwaita (and usually python3-gi / lm-sensors)
  • Install path — ~/.local/share/rnitro with a desktop entry after running the installer
  • Metrics — Apple-only sensors (SMC, Mac Low Power Mode) show as N/A on Linux

Dependencies

Ubuntu / Debian

sudo apt install python3-gi python3-venv gir1.2-adw-1 gir1.2-gtk-4.0 lm-sensors

Fedora

sudo dnf install python3-gobject gtk4 libadwaita

Also on GitHub Releases. For the polished daily driver, use macOS.

How to install

1

Install dependencies

Use the apt or dnf one-liners above for your distro.

2

Download and install

Download rNitro-v0.1-Linux-Beta-Pre-release-x64.tar.gz or install-rNitro-linux.sh, extract if needed, then run bash install-rNitro-linux.sh.

3

Use rNitro

Launch from your app menu or system tray. Monitor, Advisor, Chat, and Cleaner tabs mirror the macOS beta feature set where metrics exist.
