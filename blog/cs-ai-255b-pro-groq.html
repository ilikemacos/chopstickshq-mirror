cs.AI 2.5.5b — Pro tier, Groq, Grok-style web UI

cs.AI 2.5.5b is the announcement we wanted for Product Hunt and AlternativeTo: a real Pro effort tier on Groq, a polished web shell, and open-source paperwork for Netlify OSS.

What’s new

  • Pro tier — Groq gpt-oss-120b via our server key (sign-in required; no OpenRouter key from you)
  • Groq in the stack — Groq models in effort tiers and the web model picker
  • Grok-style web UI — icon rail, history drawer, cleaner composer layout
  • Open source — MIT license + Contributor Covenant (CoC)

The old xhigh / xhighplus tiers are gone — they alias to Pro now. Free allowance still resets every 5 hours on app, web, and Terminal CLI.
