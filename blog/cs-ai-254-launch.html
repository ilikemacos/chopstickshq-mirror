cs.AI 2.5.4 — CLI parity, Keychain, press kit

We shipped cs.AI 2.5.4 as the flagship launch for Chopsticks HQ publicity — Mac app, web agent, and Terminal CLI moving together.

What’s in 2.5.4

  • Terminal CLI — unlock keys, /search on|off, csai ask "…" --json and -q
  • Keychain — macOS cloud session stored in Keychain instead of UserDefaults
  • Deploy gate — Netlify deploys verify app zip sha256 against version.json
  • Discoverability — press kit, launch copy, guides, blog, expanded SEO keywords

Try it

macOS:

curl -fsSL https://chopstickshq.com/chopsticks-ai/install-chopsticks-ai.sh | bash

Terminal CLI:

curl -fsSL https://chopstickshq.com/chopsticks-ai/install-csai-cli.sh | bash
csai ask "hello" --json
