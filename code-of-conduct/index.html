Code of Conduct

This project follows the Contributor Covenant 2.1. The canonical file lives at the repository root: CODE_OF_CONDUCT.md.

Our pledge

We pledge to make participation a harassment-free experience for everyone, and to act in ways that contribute to an open, welcoming, diverse, inclusive, and healthy community.

Standards

  • Empathy, kindness, and respect for differing viewpoints
  • Graceful feedback; responsibility for mistakes
  • No sexualized language, harassment, trolling, or doxxing

Enforcement

Report concerns to community leaders at chopstickshq@lam.ws. Leaders will follow the impact guidelines in the full Code of Conduct (correction, warning, temporary ban, permanent ban).
